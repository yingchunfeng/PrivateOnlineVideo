# 云影匣：科技、宇宙、星空视觉调整方案

## 当前判断

参考图已具备深空底色、青紫光效、雷达上传区和数据面板，但宇宙感主要来自视频封面，而不是界面本身。大部分区域使用相近的边框、亮度和密度，主次不明显；继续增加发光描边会更杂，不会更像宇宙。

初始阶段仅开发浅色 / 深色切换及配套颜色适配；以下是当时提出的视觉增强方案，当前实现范围见文末。

更新：主题切换已独立提交并推送为 `b3419ec`。方案 A 已完成初版本地预览，并于 2026-10-28 增加 A+ 动态深空效果、全站共享背景和双层流星。第三轮进一步改为可配置的随机流星与流星雨，并补齐四项轻量动效，当前配置与验证见文末。方案 B 尚未实施；方案 A / A+ 的本地改动暂不提交。

## 两条方向

| 方向 | 视觉特征 | 优点 | 风险 |
| --- | --- | --- | --- |
| A：空间站媒体控制台（推荐） | 留白中的星图与轨道、少量仪表细节、清晰面板层级 | 兼顾长期管理、播放和双主题，可沿用现有布局 | 必须控制装饰密度，不能变成满屏仪表 |
| B：沉浸式星际影院 | 大幅星云 / 行星地平线、精选视频主视觉、更强景深 | 首页辨识度更高、氛围更浓 | 占用视频库空间，资源成本更高，不适合直接铺到所有表单 |

推荐以 A 为主，仅在登录页、空状态或后续首页精选区采用 B 的局部元素。

## 元素怎么补，补在哪里

| 层级 / 区域 | 建议补充 | 克制原则 |
| --- | --- | --- |
| 全局背景 | 远景细星点、中景淡星云、局部大轨道弧线 | 保留大面积安静背景；正文和视频画面下方不叠星点 |
| 页头与品牌 | 轨道式品牌符号、少量坐标刻度、细线分隔 | 中文标题优先；不堆无意义英文、虚构状态和随机编号 |
| 视频库 | 卡片悬停或选中时出现取景角标；明确封面、标题、元信息三级 | 不让每张卡片持续发光；不改变视频封面原始颜色 |
| 上传区 | 轨道环围绕上传入口；真实上传进度对应环形进度 | 空闲状态以静态为主，动效服务真实任务状态 |
| 播放页 | 播放器外部弱化星图纹理；数据面板使用少量刻度和分组 | 播放时降低周边亮度；绝不覆盖视频和播放控件 |
| 空状态 | 简洁卫星、星轨或观测窗口线稿 | 每页只选一个主视觉，配明确操作入口 |
| 数据与状态 | 真正可获取的容量、任务进度、视频参数 | 没有真实数据就显示未知或不显示；不编造匹配率、延迟、容量百分比 |

## 双主题统一方式

- 浅色：白色为主，冷灰蓝面板、深蓝文字、蓝色操作色；星空转为低对比星图和轨道线，不把深色简单反相。
- 深色：保留当前深空蓝黑背景和青紫强调色；后续让选中项与主操作更亮，普通边框更安静。
- 字体：中文正文保持易读；后续可为品牌 / 英文标题使用本地托管的 Space Grotesk，为时长和参数使用等宽数字，不给全站正文套装饰字体。
- 动效：最多保留一到两类重点动效，遵循减少动态效果偏好；手机端降低粒子数量，不默认上 WebGL。
- 可访问性：普通文字对比度目标不低于 4.5:1，主题选择保留文字标签、键盘焦点和选中状态；不只靠颜色表达状态。

## 建议实施顺序

1. 当前阶段：默认白色、可手动切深色、浏览器记忆、首屏预初始化、各页面颜色适配。
2. 下一阶段：只增强背景星图、页头轨道、卡片交互与空状态；先验收视频库和上传页。
3. 可选阶段：确认实际体验后，再加入登录主视觉、轻量动态星空和播放时环境弱化。

先做前两阶段即可建立风格，不建议一次把行星、流星、星云、雷达、粒子和发光边框全部叠加。

## 方案 A 初版本地预览实现

- 全局：静态星图、稀疏星点、低对比轨道和柔和星云色块；装饰层不接收点击、不进入键盘焦点。
- 品牌与页头：轨道播放标识、视频库观测图、分隔刻度；保留已有标题、导航及业务结构。
- 视频库：悬停和键盘聚焦均显示取景角标；不缩放或染色视频封面，卡片使用独立底色保证可读性。
- 上传：两种入口保留原行为，改为轨道环与取景框；空闲时静止，仅拖入文件时给予状态动效。
- 空状态：视频库、任务空状态、待上传列表采用统一的轨道播放窗口线稿。
- 任务：环形进度使用现有服务端已确认分片字节，不将字节传完等同于视频登记成功。
- 播放与参数：保留原生播放器和黑色画布，参数区增加细刻度；将原装饰版本号替换为准确的“视频文件信息”。
- 双主题与移动端：默认白色不变，深色仍可切换；小屏减少装饰，支持减少动态效果偏好，无新增字体或图像网络请求。

实现集中在 `apps/web/src/space-console.tsx` 与 `apps/web/src/space-console.css`，方便继续调节视觉强度。运行 `npm run test:space -w @online-video/web` 可生成隔离样例截图，样例封面与记录仅用于测试，不写入实际视频库。

初版不包含：沉浸式大图首页、持续动态粒子、WebGL、播放时自动降低周边亮度。其中动态星空与播放避让已在下面的 A+ 第一轮补充；其余范围保持不变。

## A+ 第一轮：动态深空控制台

保留现有导航、页头高度、视频库网格和上传布局，将视觉重点从“大轨道线”调整为“分层星空 + 行星弧光”，不增加占据视频列表空间的大横幅。

- 背景：112 个固定位置的远近星点，其中 14 个以不同周期缓慢明暗变化；蓝色与淡紫星云分布在上方、右侧和留白区域，大轨道线降低对比度。星云为静态渐变，不进行大面积模糊或逐帧重绘。
- 行星与轨道：用 SVG 渐变绘制局部行星地平线、双层大气弧光与倾斜轨道，两个节点分别以 36 秒、54 秒周期绕行。初版位于首页页头，现统一由全局 `SpaceBackdrop` 渲染；中文标题、按钮与封面保持静止和原始颜色。
- 上传：空闲时静止，悬停或键盘聚焦时节点绕行，拖入文件时光环向中心收拢；禁用入口不播放交互动画。不修改文件选择、文件夹筛选和上传队列逻辑。
- 动态开关：桌面位于侧栏外观区，手机与未登录页面位于顶部；文字明确显示开启 / 关闭 / 系统静态。使用独立键 `ov.space-motion.v1` 记忆偏好并同步同源标签页，存储受限时仍可在当前页面操作。
- 系统偏好：启用“减少动态效果”时强制显示静态星空，不允许页面开关绕过系统偏好；关闭动态后仍保留星云、星点和行星视觉。
- 播放避让：视频实际播放时暂停装饰动画，将背景装饰透明度降至 20%，不降低视频、控件和正文亮度；暂停、结束、离开页面或播放器卸载后恢复。页面进入后台时暂停装饰时间线，回到前台后继续。
- 双主题与手机：默认浅色不变；浅色使用冰蓝星图与浅色行星，深色使用深空蓝与青蓝弧光。手机仅绘制前 28 个星点并减弱装饰，保留开关状态文字和至少 44px 的操作高度。

实现仍以 `apps/web/src/space-console.tsx` 与 `apps/web/src/space-console.css` 为主，新增 `apps/web/src/space-motion.tsx` 统一处理动态偏好、系统设置、后台暂停和播放避让。第一轮未新增依赖、字体、远程图片、Canvas、WebGL、流星或鼠标视差；流星与空状态小卫星随后在第二轮补充。

### 验证方式

- `npm run typecheck -w @online-video/web`：检查业务源码和测试类型。
- `npm test -w @online-video/web`：35 项现有单元测试通过。
- `npm run test:space -w @online-video/web`：验证星点动画时间推进、轨道节点位置变化、切页背景与轨道动画实例不重建、上传悬停 / 键盘 / 拖入、开关记忆、跨标签页同步、系统偏好、模拟后台可见性以及真实媒体播放 / 暂停 / 结束 / 卸载后的恢复。
- `npm run test:theme -w @online-video/web`：双主题页面、表单、弹窗、登录与初始化场景回归。
- 生产构建使用独立新输出目录并保留旧产物，不清空或覆盖既有发布目录。

浏览器测试完全拦截样例媒体与 API，不写入真实视频库，也不访问真实 OSS。第一轮曾记录额外的 `build:release` 扫描被既有 `InstallationSettings.tsx` 中的 `AccessKey` 字段文案触发禁止标记规则。第三轮验证普通 Web 生产构建，不修改该业务页和发布扫描规则，也不将历史扫描结果当作本轮重新验证的结论。

### 全站背景共用

- 星云、星点、星图、行星弧光和绕行节点均由 `App` 外层唯一的 `SpaceBackdrop` 提供，位于业务路由和初始化检查之外。
- 首页、上传、任务、配置、系统设置、账户安全、播放、登录、初始化与不存在页面均使用同一套背景；不逐页复制装饰组件，也不改动各页布局。
- 背景固定在视口，切换业务路由不重建背景或重新启动轨道动画；双主题、动态开关、后台暂停和播放时的弱化统一作用于整套背景。
- 表单、卡片、弹窗和播放器保留独立表面；基础背景只出现在留白和页面边缘。第二轮增加的少量前景流星允许从内容上方划过，但不接收点击，并在输入、弹窗和播放时避让。

## A+ 第二轮：双层彩色流星与空状态小卫星

以下保留第二轮的历史实现记录。其中固定轨迹、固定循环和手机仅 2 条的策略已由第三轮随机调度替代；双层视觉、多色渐变、小卫星和操作避让继续保留。

- 背景流星：全局背景中保留 4 条错峰轨迹，使用青蓝、冰蓝、淡紫、暖金及双色渐变长拖尾，配发光星核和少量细碎尾迹。背景流星仍位于面板后方，保持空间层次。
- 前景流星：全站共用独立的前景层，2 条较轻的玫瑰粉 / 暖金、青蓝 / 淡紫流星允许划过视频卡片和面板；层级低于侧栏、底部导航、通知和原生模态弹窗。前景与背景均不接收点击、不进入键盘焦点，也不进入无障碍阅读顺序。
- 节奏：每条轨迹约 2 秒完成一次划过，30 秒一个循环；前后景错峰，不同时铺满屏幕，前景每 30 秒仅出现 2 次。切页保留同一组流星实例，不每页重新启动。
- 避让：输入框、文本域或选择器聚焦时隐藏并暂停前景流星；模态弹窗打开时两层流星均隐藏并暂停。播放视频或页面进入后台时，两层流星均隐藏并跟随全局时间线暂停；关闭动态或系统启用减少动态效果时不显示流星。
- 手机：隐藏前景流星，仅保留 2 条背景轨迹，缩短拖尾至 110px 并取消碎尾粒子；小屏不增加全屏 Canvas 或逐帧 JS 计算。
- 小卫星：空列表、搜索无结果、空任务和待上传列表使用带太阳能翼、镜头与天线的 SVG 小卫星。机体以 7 秒周期轻微上下漂浮，轨道光点以 20 秒周期绕行；关闭动态后保留清晰的静态插画。视频封面占位仍使用原来的轨道播放符号，不让每张视频卡片持续漂浮。
- 资源：无新增依赖、字体、图片或网络请求；使用固定少量 DOM、SVG 和 CSS 动画，不引入新的轮询定时器。

验证补充：`test:space` 检查实际流星位置变化、至少 5 种颜色、拖尾尺寸、前景绘制层级、流星星核下方卡片的点击穿透、输入避让、卫星动画与静态开关、播放 / 后台停用及手机减量；`test:theme` 补充原生确认弹窗打开时的流星避让。流星截图通过固定真实动画时间捕获，不代表日常同时出现多条流星。

## A+ 第三轮：可配置流星、流星雨与剩余动效

### 入口、保存与预览

- 桌面在侧栏“动态星空”右侧增加设置按钮；手机、登录与初始化页面在顶部同一开关右侧提供入口，保留原开关。
- 原生设置面板分为“普通流星”“流星雨”“其他动效”，桌面为右侧面板，手机为底部面板。数字项同时提供数字输入、滑块和单位；设置即时生效，不需要刷新。
- 独立使用 `ov.space-effects.v1` 保存本功能配置，与既有 `ov.space-motion.v1` 开关兼容。同源标签页通过 `storage` 事件同步；恢复默认只写本功能键，不清空其他浏览器存储，不修改服务端设置。
- “预览普通流星”持续 6 秒；“立即预览流星雨”使用当前流星雨持续时间。重复点击同一模式不叠加、不延长，切换模式替换原预览。“停止预览”立即清空预览，随后按正常间隔恢复自动调度；关闭设置面板也停止仍在进行的预览。
- 手动预览只跳过随机概率、自动触发开关和冷却，不跳过全局动态开关、系统减少动态效果、后台、播放、业务弹窗及设备安全上限。设置面板用 `data-space-settings` 明确区分，不因自身 `dialog[open]` 规则遮掉预览；业务确认弹窗仍正常避让。
- 系统减少动态效果时仍可编辑保存，面板说明“动画和预览当前不会播放”，预览按钮禁用。存储读取或写入受限时改用本页内存状态并提示不能保证刷新记忆或跨标签页同步。

### 当前配置与默认值

前景比例、概率使用百分数；间隔、飞行时长、持续时间和冷却使用秒；尺寸、拖尾与发光使用倍率。

| 配置项 | 普通流星默认 | 流星雨默认 | 可保存范围 |
| --- | --- | --- | --- |
| 普通开关 / 流星雨自动开关 | 开 | 开 | 开 / 关 |
| 每批最少～最多数量 | 1～3 条 | 3～6 条 | 各 1～24 条 |
| 前后景合计同屏上限 | 6 条 | 24 条 | 1～48 条，另受设备硬上限限制 |
| 相邻两批开始间隔 | 0.6～1.8 秒 | 0.16～0.38 秒 | 各 0.1～60 秒 |
| 尺寸倍率 | 0.6～2.4 倍 | 0.4～2 倍 | 各 0.2～4 倍 |
| 每条飞行时长 | 1.2～2.8 秒 | 1～2.4 秒 | 各 0.5～8 秒 |
| 拖尾长度倍率 | 1 倍 | 0.85 倍 | 0.3～3 倍 |
| 发光强度 | 1 倍 | 0.8 倍 | 0～2 倍 |
| 前景开关 / 比例 | 开 / 20% | 开 / 18% | 开 / 关，0～100% |
| 色板 | 青蓝、冰蓝、淡紫、玫瑰、暖金 | 相同，独立配置 | 至少一种有效颜色 |
| 双色渐变拖尾 | 开 | 开 | 开 / 关 |
| 自动触发概率 | 不适用 | 5% | 0～100% |
| 持续发射时间 | 不适用 | 8 秒 | 1～30 秒 |
| 两场冷却时间 | 不适用 | 60 秒 | 5～600 秒 |

- 每批数量不等于同屏上限，也不等于发射间隔；前景与背景合计占用同一模式的上限。实际批次范围还会降低到该模式的同屏上限，剩余槽位不足每批最少数量时整批跳过，不补发欠下的数量。
- 每条流星独立生成位置、路径、飞行时长、尺寸及颜色，尺寸分布偏向小流星并保留少量明显大流星。尺寸缩放放在内部星体上，星核、线宽、光晕和拖尾协调改变，不缩放飞行路径。
- 数字空值、NaN、非数字、无穷、负数和极端值均校验；配置归一化限制合法范围，反向区间自动排序。损坏 JSON 或不合法字段逐项回退默认，色板不会为空。输入框暂时无效的内容不写入设置，失焦恢复上次合法值。
- 修改后续批次的参数不会重置已经发出的流星路径、尺寸与飞行时长；关闭某模式的前景开关会立即移除该模式的现有前景。修改活动流星雨持续时间时按原开始时间重新计算结束时刻，冷却修改也按原冷却起点重新计算，不必等旧场次或旧冷却结束才生效。

### 概率语义与调度

“5%”表示：在每次满足条件的普通流星发射机会，独立抽取一次，绝非每帧抽取。条件为普通模式开启、自动流星雨开启、当前不在雨中或退场中、冷却结束、页面可见、未播放视频、没有业务弹窗且未聚焦输入控件。普通流星已达同屏上限时仍算发射机会，但不会突破并发上限。

- 0% 永不自动触发；100% 在满足条件后的首个普通发射机会触发，仍受冷却约束。雨中不会再判断启动下一场雨，不允许多场叠加。
- 冷却从持续发射结束起计算；被安全规则中断时从中断时刻计算。预览可以跳过冷却，但停止预览后自动模式仍遵守冷却。
- 流星雨开始时逐步累积同屏数量，批次在配置的最少与最多数量间渐变；结束前减弱新批次，然后停止雨发射，已有雨粒子自然离场。退场期间不叠加普通发射，全部雨粒子离场后再等一个普通间隔恢复，避免普通模式承接超过自身上限的雨粒子。
- 自定义雨上限低于正在飞行的普通流星数量时，进入雨模式会安全裁剪存量；恢复普通模式也按最新普通上限约束存量。自然退场不会把两套并发上限相加。
- `SpaceMeteorProvider` 位于路由上方，持有唯一 `SpaceMeteorEngine` 与一个可取消的最近事件计时器，只在发射、粒子到期、模式边界或安全事件时更新，不按帧更新 React。切换页面不新建调度器、不重建全局背景。
- 关闭动态、播放、业务弹窗和后台立即停止发射并清空流星；恢复后等待下一次新间隔，不补发积压。输入时隐藏并暂停前景，后续普通批次可转到背景，但禁止自动雨的概率判断。装饰层不接收点击，低于重要导航、通知及业务弹窗。

### 四项轻量增强

- 星云慢漂移：仅现有一层低对比星云，72 秒周期、小幅 `transform`，不动画模糊。
- 导航轨道指示：绝对定位的独立标记以 320ms 移至当前侧栏链接；原六个链接、`aria-current` 与焦点保持不变。关闭动态后位置仍准确，仅取消移动过渡。
- 任务完成光环：上传执行器只在本会话收到经过校验的后端登记成功结果后，向 `TaskCompletionEffects` 记录一次。TaskCard 在 1.5 秒有效窗口内消费一次并播放约 0.9 秒双环；历史已完成、上传 100%、失败、轮询、重复进入和补封面不会反复播放。关闭动态或未及时展示的成功不在后来补播。
- 标题与首屏模块：每次路由进入最多分别淡入一次，位移 7px、时长 320ms、模块延迟 70ms；不依赖查询参数、翻页或普通刷新，背景保留同一实例。首次全局偏好尚未初始化时只等待初始化一次。

四项均有独立开关，默认全开，仍服从全局开关与系统减少动态效果；播放和后台遵守统一暂停 / 停用策略。
